LOCAL WORKSPACE

Your research stays on this device.

This deployable TenderAtlas package is a local-first public procurement research interface. It has no user login or remotely stored personal workspace.

What remains in your browser

Bookmarks, saved notice snapshots, profile keywords, watchlists, bid stages and personal research notes are saved using browser localStorage. You can export these records as a JSON backup, import them on another device manually or clear them from Settings. Browser storage can be removed by privacy modes, browser cleanup and device changes.

What is transmitted

When you search, your search query and selected filters are sent to the TenderAtlas API endpoint on the Cloudflare deployment. The Worker queries the selected official procurement sources to return public notice data. On search execution, source requests can include your search terms and territory selection. Search results may be cached temporarily at the edge. We do not request or send your company profile or saved notes to the Worker.

Optional integrations

If SAM.gov is configured by the deployer, its API key is a server-side secret and is not sent to the visitor's browser. This ZIP does not activate email automation, credit-card payments, cross-device accounts or third-party analytics. Its optional service worker caches only the static application shell for offline use, not official API responses or your private notes on a server.

Operator responsibilities

The deployment operator is responsible for the domain, any upstream server logs and any separate analytics, legal notices or privacy disclosures they later enable. This document describes only the behavior of the supplied ZIP and is not a substitute for an operator-specific privacy policy.
