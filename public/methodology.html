OPEN DATA / SOURCE INTEGRITY

A transparent approach to procurement intelligence.

TenderAtlas provides research assistance using live requests to official public procurement services. It is independent of those publishers and never creates synthetic opportunity records.

Where the data comes from

European Union - TED

The TED Search API is queried with a date window, optional text and country filters, and a bounded result page. This edition limits the search to the documented competition form type, but each notice and bid deadline still requires verification at the official publisher.

Official API documentation

Greece - KIMDIS

The KIMDIS Open Data service is queried using POST and a JSON body. Calls retrieve published invitations and procurement notices. The original public PDF is linked by its ADAM reference.

Official API documentation

United Kingdom - Find a Tender

Open Contracting Data Standard release packages contain recent or updated procurement records. The tool retrieves a bounded updated-release sample. Keyword filtering happens within the fetched page and is not exhaustive national search.

Official API documentation

United States - SAM.gov

SAM.gov Public Opportunities requires a server-side API key; this connector is disabled when the key is missing. Data is never invented as a substitute.

Official API documentation

How to interpret a notice

Publication dates, budgets, award status, classifications and submission deadlines may be missing, updated or unclear. A listed deadline does not prove that bidding remains open. TenderAtlas only reports a deadline when the upstream record provided it; a date not provided by the source is marked unverified.

Figures on the dashboard are computed solely from the retrieved bounded source sample for the current search and must not be interpreted as full-market estimates, total annual procurement volume or global coverage.

What relevance scoring means

When you save a company profile, TenderAtlas computes an explainable heuristic from matching title terms, description terms, relevant CPV categories and selected markets. It does not predict contract wins, determine legal eligibility or replace reading the official documentation. A country match alone deliberately receives only a minimal score. The score is not an award probability.

Data use and freshness

Upstream data can be delayed or inconsistent. Edge caching reduces duplicate requests for a short interval. Source failures and partial coverage are displayed, rather than silently replaced with invented notices. For regulated decisions, always open the primary notice and use its official attachments.

Local workspace and service boundaries

Bookmarks, notes, profile data and saved searches are stored in your browser. This ZIP does not provide cross-device sync, user accounts, email digests or a working Stripe subscription. Those services require explicit backend configuration and verified access control.

Additional Official Registers (v10.6)

  • France BOAMP (OpenDataSoft API v2.1): Official French public procurement notices. Buyer name is taken strictly from nomacheteur (null if omitted).
  • World Bank Global Procurement (Procurement Notices API v2): Covers World Bank-financed projects across 170+ countries (not all national procurement). ISO-2 codes are normalized to ISO-3, and results are post-filtered by UTC date window and keywords.
